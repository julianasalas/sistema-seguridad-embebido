enum Estado

#include <sistema_seguridad.cpp>

Estados de la Máquina de Estados Finita del sistema.

El diagrama completo de transiciones se encuentra en la documentación del archivo principal (sistema_seguridad_doxygen.ino).

  • EST_INICIO — Pantalla de bienvenida; espera RFID o clave.
  • EST_ABRIENDO — Servo abierto; cuenta ticks hasta cerrarse.
  • EST_CONFIG — Submenú de configuración de clave y RFID.
  • EST_MONITOR_INTRUSOS — Monitorea movimiento, ruido y puerta abierta.
  • EST_MONITOR_AMBIENTAL — Monitorea temperatura y nivel de luz.
  • EST_ALARMA — Sirena y LED activos durante N ticks.
  • EST_BLOQUEO — Sistema bloqueado; solo admin o botón desbloquea.

◆ activarAlarma()

void activarAlarma ( String razon,
Estado origen )

#include <sistema_seguridad.cpp>

Registra y activa una alarma del sistema.

Guarda el estado de origen en estadoAnterior para restaurarlo al finalizar la alarma. Controla el contador de alarmas consecutivas: si la alarma ocurre dentro de TICKS_VENTANA ticks desde la anterior, incrementa alarmasConsec; de lo contrario lo reinicia a 1. Al alcanzar MAX_ALARMAS alarmas consecutivas, manejarAlarma() transicionará a EST_BLOQUEO en lugar de regresar al estado anterior.

Parámetros
[in]razonCadena de hasta 16 caracteres con la causa de la alarma.
[in]origenEstado desde el cual se dispara la alarma.
Returns
Nothing.

◆ manejarAlarma()

void manejarAlarma ( )

#include <sistema_seguridad.cpp>

Manejador del estado EST_ALARMA.

Gestiona el parpadeo del LED rojo y la duración total de la alarma usando únicamente contadores de ticks:

  • LED encendido TICKS_PARP_ON ticks → apagado (noTone).
  • LED apagado TICKS_PARP_OFF ticks → encendido (tone 900 Hz).

Al cumplirse TICKS_ALARMA ticks totales, limpia salidas y:

  • alarmasConsec >= MAX_ALARMAS → irAEstado() a EST_BLOQUEO.
  • En caso contrario → irAEstado() a estadoAnterior.
Returns
Nothing.

◆ manejarBloqueo()

void manejarBloqueo ( )

#include <sistema_seguridad.cpp>

Manejador del estado EST_BLOQUEO.

Parpadea el LED rojo con tiempos distintos al de alarma (TICKS_PARP_BLQ_ON / TICKS_PARP_BLQ_OFF) para diferenciación visual.

El sistema se desbloquea de dos formas:

  • Botón físico — botonPresionado() retorna true: reinicia contadores y llama a irAEstado() a EST_INICIO.
  • Clave de administrador — el operador ingresa claveAdmin y confirma con '#':
    • Correcta → irAEstado() a EST_CONFIG.
    • Incorrecta → mensaje de error y regresa a pantalla de bloqueo.

Nothing.

◆ manejarInicio()

void manejarInicio ( )

#include <sistema_seguridad.cpp>

Manejador del estado EST_INICIO.

Invocado por TaskControl en cada tick. Llama a verificarRFID() y lee el teclado:

  • '*' — Limpia textoClave y remuestra la pantalla de bienvenida.
  • '#' — Evalúa la clave:
    • Correcta → beep + irAEstado() a EST_ABRIENDO.
    • Incorrecta → incrementa intentosFallidos; al llegar a 3, llama a irAEstado() a EST_BLOQUEO.
  • Dígito — Concatena a textoClave y muestra asteriscos en el LCD.
Returns
Nothing.
