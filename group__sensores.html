◆ hallDet()

bool hallDet ( )

#include <sistema_seguridad.cpp>

Detecta campo magnético con el sensor Hall KY-035.

Compara la lectura de PIN_HALL con HALL_REPOSO. Si la desviación absoluta supera HALL_MARGEN, se interpreta como presencia de un objeto con imán (movimiento de persona/objeto). Tres lecturas positivas consecutivas en TaskIntrusos() disparan la alarma.

Valores devueltos
trueCampo magnético detectado.
falseSensor en reposo; sin detección.

◆ leerTemp()

float leerTemp ( )

#include <sistema_seguridad.cpp>

Lee la temperatura con el termistor NTC del KY-013.

Convierte la lectura ADC del pin PIN_TEMP a temperatura mediante la ecuación de Steinhart-Hart de tres coeficientes:

float R2 = TERM_R1 * (1023.0 / Vo - 1.0);
float logR2 = log(R2);
float T = 1.0 / (A + B*logR2 + C*logR2^3);
return T - 273.15;
TERM_R1
#define TERM_R1
Resistencia de referencia KY-013 (10 kΩ).
